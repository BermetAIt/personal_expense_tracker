# Visual Validation

The supplied prototype in `../reference/money-tracker-v3.html` is the visual baseline. Before a release, capture the running application in these states and replace the placeholders linked from the root README:

- `screenshots/light.png`: desktop, light theme, transactions page
- `screenshots/dark.png`: desktop, dark theme, statistics page
- `screenshots/mobile.png`: 375px-wide viewport, mobile navigation visible

Check that the monthly summary, chart labels, category controls, and navigation remain readable without horizontal overflow.
